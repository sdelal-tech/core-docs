# Источники и проверки

[Оглавление](../README.md) · [Правила агента](../AGENTS.md)

## Проверенная версия

Текущие версия, дата, URL, размеры и SHA-256 закреплены в [манифесте](../reference/source-manifest.json). При обновлении 25.09.2026 сопоставлены 32 файла v190, 34 файла v191 и 34 ответа latest. Файлы предыдущей версии сначала проверены по сохранённым хешам. Копии исходного Core в репозитории не хранятся: сборка и проверки читают CDN.

У 31 файла latest и v191 совпали байты. `.readme.html`, `importmap.js` и `importmap.min.js` отличаются адресами канала; после замены только этих адресов содержимое совпало. Это результат на дату проверки, не постоянное тождество latest и версии.

Десять функциональных JS-модулей, их минифицированные варианты и прежние темы совпали с v190. Их контрактные описания сохранены; влияние новой темы на компоненты проверяется отдельно.

## Что изменилось в v191

- Добавлены `theme-nkui.css` и минифицированный вариант: палитра NKUI, Inter, компактные контролы и горизонтальные radio-сегменты. Подключение, размеры и режимы — в разделе [тем](themes.md).
- В `core.css` добавлены `--f-w-thin: 300` и `core-text-thin`, верхние координаты `core-t-56x`/`core-t-64x` и их t/m-варианты. Удалений классов и токенов нет.
- Каталог CDN объявляет NKUI, адреса importmap указывают на новую версию. Сам файл NKUI из v191 импортирует NK из `latest`: зависимость остаётся изменяемой.

## Что изменилось в v190

- Режимы цвета выбираются классами `core-theme-light/dark`; data-theme больше не является переключателем CSS.
- Интерфейсная шкала использует `--f-s-base` вместо глобального html/rem. Старый `--rem-base` в теме NK не меняет новую шкалу.
- Размеры иконок числовые: прежний `core-icon-m` заменяется на `core-icon-8x`; маска задаётся на элементе через `--im-img`.
- Grid использует `--grid`; неравные готовые сетки удалены. Их примеры задают треки переменной на обёртке: сетка наследует их и переопределяет адаптивным классом на узком экране.
- Удалены `core-form-item`, `core-form-item-inline`, `core-label`: примеры используют композицию row/col, gap и текстовых классов.
- Таблицы используют `core-table-border-x/y/head` и общую обёртку `core-x-scroll`. Старые специализированные обёртки удалены.
- Основание заголовков — точные `core-h1` … `core-h6`; адаптация размера выполняется t/m-текстовыми классами. Удалены старые `core-text-muted*`, `core-text-b`, `core-text-inverse`, `core-popup-zero`, `core-overflow-none` и адаптивные border-none.
- Исправлены t/m-алиасы позиционирования, fallback направленного padding и границы disabled checkbox/radio. `--b-r`, `--t`, `--b` зарегистрированы как ненаследуемые; радиус контролов светлой SS увеличен до `--b-r-8x`.
- Reset, области метрик, row/col-reverse, скроллбары и порядок правил переработаны. У slider есть `core-slider-scrollbar`. Устаревшие анимационные defaults JS остаются отдельным ограничением.

Подробности и действующие ограничения — в [реестре](pitfalls.md). Предыдущие состояния документации доступны в Git-истории.

## Справочники и сборка

PostCSS разбирает пять CSS-файлов документированной версии после проверки SHA-256. [Классы](https://sdelal-tech.github.io/core-docs/reference/classes.json), [токены](https://sdelal-tech.github.io/core-docs/reference/tokens.json) и [индекс](https://sdelal-tech.github.io/core-docs/chapters/class-index.md) генерируются автоматически. Каталог классов основан на `core.css`, каталог токенов включает все четыре темы. Каталоги показывают исходные декларации, строки и области, а не вычисленные default. Счётчики находятся в самих каталогах.

Редактируемые источники находятся в `content/`: главы, JSON примеров и метаданных, код просмотрщика. `npm run build` заново создаёт игнорируемый `docs/`: 42 главы, 87 примера, HTML, JSON и [агентский ZIP](https://sdelal-tech.github.io/core-docs/core-agent.zip) с Markdown/JSON без HTML. Оформление задаётся штатным Core; собственных CSS-правил нет. Версия в интерфейсе и метаданных сборки берётся из одного манифеста.

## Текущие проверки

`npm test` проверяет сравнение версий, целостность Markdown/JSON, публичные ссылки, классы примеров, отсутствие собственного CSS, все SHA-256 документированной версии и доступность latest. `npm run test:browser` проверяет загрузку 87 примеров, выбранные действия JS, действительную смену цветов, сохранение ввода, границы адаптивности, ошибки CDN и повторную загрузку. Точные CSS-пробы загружают версию из манифеста. `npm run test:layout` проверяет оболочку, навигацию и мобильное меню. Все сетевые проверки используют настоящий CDN.

Один успешный запрос CSS не доказывает оформление компонента. Для изменений тем, сеток и общих метрик нужны вычисленные размеры, действия и визуальный просмотр. Отчёты прошлых версий не считаются результатом текущего прогона.

Новые версии проверяются только по запросу владельца. `check:upstream` возвращает код 2 при изменениях. `docs:diff -- --to latest` один раз выбирает конкретную версию и готовит отчёт в `work/core-update/`, не меняя принятый манифест. Общие и непокрытые изменения явно отмечаются. Порядок принятия — в [инструкции автора](https://github.com/sdelal-tech/core-docs/blob/main/UPDATE.md).

Обычная сборка не принимает новую версию. Недоступность CDN или изменённый SHA-256 версии останавливает публикацию. Расхождение изменяемого latest показывается диагностикой; дата его последней сверки сохраняется в манифесте отдельно от даты обновления документации.

## Границы достоверности

Инициализация всех примеров не означает перебор всех состояний каждого компонента. Проверки выполняются в Chromium; Safari, Firefox и скринридеры не проверялись. Шрифты загружаются штатной темой, но все платформы и начертания не покрыты. Минифицированные файлы проверены по хешам; их семантическая эквивалентность исходникам не заявляется. Сетевые сбои могут остановить проверки при неизменной документации.
